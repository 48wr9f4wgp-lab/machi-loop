# MACHI LOOP — Privacy Policy Draft v1

Status: **PRE-RC DRAFT — NOT READY TO PUBLISH AS-IS**
Final text must match the actual released binary, providers, data destinations and contact/URL information.

## Draft structure
MACHI LOOPはゲーム提供に必要な情報を最小限に扱うことを基本方針とします。

### 1. ゲームデータ
都市進行、設定、セーブ等を端末内に保存します。v1.0設計ではアカウント登録は不要です。

### 2. 分析情報
External Analyticsを無効にする場合、ゲームプレイデータを外部分析サービスへ送信しません。有効化する場合は、品質改善等に必要な非直接識別情報のみを対象とし、氏名、メール、住所、正確な位置情報、自由入力、認証情報、秘密鍵、セーブ全文はゲーム分析用途で送信しません。公開前に実Provider・送信先・目的・識別子の扱いを確定します。

### 3. クラッシュ/エラー
有効化する場合のみ、アプリ版、プラットフォーム、正規化したエラー分類、限定された操作履歴等を扱います。公開前に実Providerと収集項目を確定します。

### 4. 広告・トラッキング
最終バイナリの実態に合わせて記載します。広告/トラッキングを導入していない状態でのみ「利用しない」と確定できます。

### 5. 公開前必須
実際のSDK/ネットワーク挙動、Apple App Privacy、Google Play Data safety、問い合わせ先、公開URL、保存/削除方針を最終照合してから公開します。
