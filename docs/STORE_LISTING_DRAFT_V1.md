### Full description draft
`道路一本で、街はどう変わる？`

`MACHI LOOP`は、街づくりの「考える面白さ」を残しながら、細かな作業を圧縮した3D都市シミュレーションです。

あなたが描くのは、街の骨格になる**幹線道路**。その周囲には地域道路や住宅・商業・工業が自動で育ち、人口、雇用、交通、財政が変化していきます。

**街の流れをデザイン**
- 幹線道路を描く
- 混雑した道路を拡幅する
- 迂回路をつくって渋滞を解消する
- 不要な道路を整理して維持費を抑える

**数字だけではなく、景色が育つ**
小さな街から始まり、都市ランクが上がるほど建物の密度とスカイラインが変化。自分の道路設計が、そのまま街の姿になります。

**問題は、作業ではなく判断で解く**
住宅・商業・工業の需要、交通、財政、都市サービスを読みながら、次の一手を選びます。悪化した街も、道路や方針を見直して立て直せます。

**短時間でも遊べる都市運営**
1本の道路を追加するだけでも街は反応します。数分のプレイから、じっくり都市計画まで、自分のペースで続けられます。
